# Manual test script

For a person, or an agent driving a browser. Run `deno task dev` and open the local URL with `?seed=121`. Before each section, reload. To read logical state, use `game.state` in the console. To read what has played, use the panel beside the grid, including the `#live` text, or look at the marker.

**Promotion rule:** a bug found by hand or by an agent becomes a permanent test in `core/` before it is fixed, unless it truly lives in `game/`, in which case add a step here.

| #  | Action                                                         | Expected observation                                                                                                                                                                                         |
| -- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1  | Load the page                                                  | One canvas. A brown marker on a map of sand, green oasis, red lava, and gray currents. The goal text shows in the panel. No console errors.                                                                  |
| 2  | Tap the right arrow                                            | The marker slides one cell east. `#live` says `moved to 1, 0`. `player` is `{ x: 1, y: 0 }`.                                                                                                                 |
| 3  | Walk until lava or currents are ahead, then press toward it    | The marker lurches and flashes red, then returns to its cell. `#live` says `blocked by lava; requires Lavawalker's Incantation` or `blocked by currents; requires Glider's Plume`. `player` has not changed. |
| 4  | Tap an arrow during a walk                                     | The tap waits. The marker finishes the walk, then takes that step. It never skips a cell.                                                                                                                    |
| 5  | Mash arrows quickly, then stop                                 | The marker settles on the cell `player` reports.                                                                                                                                                             |
| 6  | Hold an arrow down                                             | The marker keeps walking. Holding into a wall repeats the bump.                                                                                                                                              |
| 7  | Load `?seed=7`                                                 | A different map.                                                                                                                                                                                             |
| 8  | Run `game.state` in the console                                | Plain data: `seed`, `player`, `inventory`, `changed`, and `ended`. No terrain list. `changed` holds only cells you gathered.                                                                                 |
| 9  | Press an arrow several times                                   | Position and Terrain in the panel change as each step plays, and never ahead of the marker.                                                                                                                  |
| 10 | Make the window short, then press the down arrow               | The page does not scroll. The marker moves.                                                                                                                                                                  |
| 11 | Click the sound button, then press an arrow                    | The button reads `Sound: off`, and the arrow still moves the marker.                                                                                                                                         |
| 12 | Click the sound button again                                   | The button reads `Sound: on`, and you hear a two-note chime.                                                                                                                                                 |
| 13 | Tab to the sound button and press Space                        | It toggles. Arrow keys still move the marker.                                                                                                                                                                |
| 14 | Listen while walking and bumping (headphones or speakers)      | A soft tick on each step, and a low buzz on each bump. **This is the only check that a person can hear them.**                                                                                               |
| 15 | On a high-resolution display, or at browser zoom 200%          | Grid edges stay sharp. The marker stays centered. Run `document.querySelector("canvas").width`: it is the canvas `clientWidth` times `devicePixelRatio`.                                                     |
| 16 | Tap 'e' on traversable terrain                                 | The marker pops and a gather sound plays. `#live` says `gathered charcoal at x, y` (or papyrus). A gray dot stays on the cell. The Inventory list updates as the pop starts, not before.                     |
| 17 | Tap 'e' on harvested cells                                     | Hear a low buzz when stopped from gathering. `#live` says `gather failed at x, y`                                                                                                                            |
| 18 | Walk toward lava before crafting the Lavawalker's Incantation  | The marker stays outside the lava cell. `#live` says `blocked by lava; requires Lavawalker's Incantation`. The player's position is unchanged.                                                               |
| 19 | Craft the Lavawalker's Incantation, then walk toward lava      | The marker enters lava because the player holds the incantation. `#live` says `moved to x, y`.                                                                                                               |
| 20 | Craft a recipe you can't afford                                | A low buzz. `#live` says `craft failed: missing ...`. Inventory is unchanged.                                                                                                                                |
| 21 | Tab to a ready recipe and press Enter                          | A chime. The inputs leave the Inventory and the crafted item appears. Arrows still move the marker.                                                                                                          |
| 22 | Set `WALK_MS` to 3000, then gather                             | The recipe list does not change until the pop finishes. Set `WALK_MS` back to 120 afterward.                                                                                                                 |
| 23 | Craft Glider's Plume, then walk toward currents                | The marker enters currents. Gathering there gives wind's breath.                                                                                                                                             |
| 24 | Craft The Last Chronicle                                       | The win banner appears and an ending chord plays. Arrows, 'e', and recipe buttons do nothing after that.                                                                                                     |
| 25 | Play to the ending, then run `game.controller.recorded.length` | About 95, the number of commands the game takes.                                                                                                                                                             |
